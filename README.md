# AI Daily Mentor 🤖

Автономный Telegram-бот на базе **Google Gemini API** и **GitHub Actions**, который ежедневно присылает персонализированный план обучения, ведёт трекер прогресса и генерирует утренние технические микро-задачи.

## Архитектура и ключевые особенности

* **Serverless-автоматизация:** работает полностью в облаке по расписанию (`cron`) через GitHub Actions без необходимости держать включённым локальный сервер.
* **Отказоустойчивость (Fallback-механизм):** реализован каскадный перебор языковых моделей с обработкой исключений при перегрузке API (`503 UNAVAILABLE`) и жёсткими таймаутами выполнения.
* **Динамический контекст:** автоматический расчёт прогресса (streak-счётчик) и ротация тематики заданий по дням недели (Python, дискретная математика, технический английский, подготовка к собеседованиям).
* **Безопасность:** все токены и API-ключи изолированы через переменные окружения (`os.environ`) и зашифрованы в GitHub Secrets.

## Стек технологий

* **Язык:** Python 3.12
* **AI & API:** Google GenAI SDK (`google-genai`), Telegram Bot API (`requests`)
* **CI/CD:** GitHub Actions
